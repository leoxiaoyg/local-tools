# 本地历史说明书

首页新增“最近处理”，给反复使用工具的人一个轻量回看区。

## 1. 这是什么

- 记录最近 `20` 条处理记录
- 只保存在当前浏览器本机
- 不上传文件内容，不走账号，不跨设备同步
- 可一键清空

## 2. 会记住什么

首刀记录的是一次“成功处理”的摘要，通常包括：

- 工具名
- 处理时间
- 输入文件或动作摘要
- 输出文件名或结果摘要

例如：

- `a.jpg -> compressed.jpg`
- `shop.csv 等 3 个 -> cleaned-csv.zip (成功 2 · 失败 1)`
- `格式化 JSON`

## 3. 怎么用

1. 先正常使用任一工具完成一次处理。
2. 回到首页 `/`。
3. 在“最近处理”里查看最新记录。
4. 点击某一条会回到对应工具页。
5. 不再需要时，点“清空”。

## 4. 边界

本刀故意做薄，不做下面这些：

- 不保存原文件
- 不保存失败中的中间状态
- 不做搜索、筛选、固定置顶
- 不跨浏览器、跨机器同步

## 5. 隐私说明

记录保存在浏览器本地存储里，和 `lt-lang` 一样只留在这台机器当前浏览器。清浏览器站点数据或点首页“清空”后，历史会消失。
