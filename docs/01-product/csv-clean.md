# CSV 清洗说明书

面向要在本机去掉空行、重复行、只留几列的人。文件只在这台电脑上处理。不做透视或公式。

网页入口：`/csv-clean.html`。命令行：`python -m app csv clean`。

## 1. 能做什么 / 不能做什么

| 做 | 不做（本刀） |
|---|---|
| 去掉整行空白（单元格去空格后全空） | 透视、分组汇总 |
| 去掉完全相同的数据行，保留第一次出现 | 按某一列模糊去重 |
| 按列名或 1 起的列序号留列 | 改列名、公式、Excel 清洗 |
| 单文件下载；多文件 zip | 改写原文件 |

第一行必须是表头。输出带 UTF-8 BOM（`utf-8-sig`），方便 Excel 打开中文。

## 2. 网页怎么用

1. 拖入 `.csv`，可多选。列表可单条删除，顶部清除会清空。
2. 默认勾选「去掉空行」和「去掉完全相同的行」。要保留时取消勾选。
3. 「保留的列」可空（全留），或填 `sku,name` / `1,3`（中文逗号也可）。
4. 单文件直接下载 `*_clean.csv`；多文件打成 zip。

## 3. 上限

单文件 20MB、最多 20 万行；一批最多 50 个、合计 200MB。
