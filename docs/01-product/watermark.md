# 文字水印说明书

面向要在发布前给商品图加店名或简短说明的人。文件只在这台电脑上处理。

网页入口：`/watermark.html`。命令行：`python -m app image watermark`。

## 1. 能做什么 / 不能做什么

| 做 | 不做（本刀） |
|---|---|
| 一行文字，最多 40 字 | 图片水印、Logo 贴图 |
| 五个位置：右下、左下、右上、左上、居中 | 视频水印、PDF 水印 |
| 斜向重复铺满整张图 | 自选颜色、字体文件上传 |
| 透明度 10～100 | 上传字体文件 |
| 白字 + 深色描边，字号随图片变 | 改写原文件 |
| 单张下载；多张 zip | - |

中文店名需要本机有中文字体（Windows 一般已有微软雅黑）。没有可用字体时会明确报错。

## 2. 网页怎么用

1. 拖入图片，可多选。列表可单条删除，顶部清除会清空。
2. 填水印文字，选位置和透明度（默认 40）。
3. 若想铺满整张，勾“铺满整张（斜向重复）”；勾上后不再看“位置”。
4. 单张直接下载；多张打成 zip。

## 3. 上限

与图片压缩相同：单文件 50MB；一批最多 50 张、合计 200MB。
