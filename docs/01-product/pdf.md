# PDF 工具说明书

面向要在本机处理发票、合同、商品说明 PDF 的人。文件只在这台电脑上读和写。

网页入口：`/pdf.html`。命令行见 `docs/01-product/cli.md`。

## 1. 能做什么 / 不能做什么

| 做 | 不做 |
|---|---|
| 合并 2–30 个 PDF | 在合并 / 压缩 / 拆分时直接处理已加密文件（先解密） |
| 压缩（轻度 / 标准 / 强力） | 云端备份密码 |
| 按页拆成 zip，或按页码提取 | 声称「跨境合规」或法律认证 |
| AES-256 加密、设置打印/修改/复制/批注权限 | 破解他人加密文件 |
| 已有打开密码时，生成无密码副本（不是破解） | 改写原文件；破解他人文件 |

密码只在本机使用。加密有助于控制谁能打开文件，**不是法律或合规认证**。

## 2. 网页怎么用

1. 选操作：合并、压缩、拆分、加密 / 权限、或「我有密码，生成无密码副本」。
2. 拖入 PDF。合并、压缩、加密、生成无锁副本可多选；拆分一次 1 个。选了多个时，列表每条有「删除」，顶部「清除」清空全部。
3. 加密必须填打开密码；权限密码可空，默认与打开密码相同。勾选允许的操作，全不勾则只能打开查看。
4. 生成无锁副本必须填当前打开密码。错密码会失败。原文件不改。
5. 单文件直接下载 PDF；多文件打成 zip。

## 3. 上限

| 类型 | 上限 |
|---|---|
| 单文件 | 80MB |
| 合并 / 一批 | 最多 30 个，合计 200MB |
| 按页拆分 | 最多 400 页 |
