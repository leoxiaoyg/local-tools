# PDF 加密 / 权限 冒烟（P0）

网页在本机服务打开 `/pdf.html`。CLI 也可跑 `python tests/cli_smoke.py`（含第 13–15 条）。

| ID | 步骤 | 期望 | 结果 |
|---|---|---|---|
| P0-1 | 选「加密 / 权限」，上传未加密 PDF，填打开密码，开始处理 | 下载 `*_locked.pdf`；用错误密码打不开 | |
| P0-2 | 用正确密码打开加密结果 | 能打开；话术不含「合规认证」 | |
| P0-3 | 取消全部权限后再加密 | 文件仍能打开查看 | |
| P0-4 | 不填打开密码就提交 | 提示填写打开密码，不发起请求 | |
| P0-5 | 选「我有密码，生成无密码副本」，上传加密文件，填正确密码 | 下载 `*_unlocked.pdf`，无需密码可开 | |
| P0-6 | 错误密码解密 | 提示密码不正确 | |
| P0-7 | 对加密文件做合并或压缩 | 提示先解密或提供密码 | |
| P0-8 | 切换 EN | 按钮与错误为英文 | |
| P0-9 | CLI：`pdf encrypt --user-pw secret` 再 `pdf decrypt --password secret` | 与 `cli-smoke.md` 13–15 一致 | |
| P0-10 | 多选至少 2 个 PDF，点其中一条「删除」 | 该文件从列表去掉；其余仍在；顶部「清除」仍清空全部 | |

## 不测（本里程碑）

破解他人文件、证书/DRM、云端存密码、exe。
