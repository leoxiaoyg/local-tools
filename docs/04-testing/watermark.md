# 文字水印 冒烟（P0）

网页打开用户正在用的那个 origin 上的 `/watermark.html`（先确认端口，勿另起一个自测过了就算）。CLI 也可跑 `python tests/cli_smoke.py`（含第 16 条）。

| ID | 步骤 | 期望 | 结果 |
|---|---|---|---|
| P0-1 | 上传 1 张静图，填「店名」，默认右下 / 40，开始 | 下载 `*_wm.*`；图上能看到文字 | |
| P0-2 | 不填文字就提交 | 提示填写水印文字，不发起请求 | |
| P0-3 | 多选 2 张，点其中一条删除后再处理 | 只处理剩下的；多张为 zip | |
| P0-4 | 切换 EN | 按钮与提示为英文 | |
| P0-5 | CLI：`image watermark a.jpg --text Shop -o out.jpg` | 产出文件 | |
| P0-6 | 对当前 origin `POST /api/image/watermark` | 不是 405 | |

## 不测（本里程碑）

铺满、图片水印、视频 / PDF 水印、自定义字体。
