# 本地历史冒烟（P0）

默认用用户实际在看的地址验证：`http://127.0.0.1:8765/`。

| # | 步骤 | 输入 | 预期 | 结果 |
|---|---|---|---|---|
| 1 | 打开首页 | 无 | 出现“最近处理”区块；无记录时显示空态，清空按钮禁用 | |
| 2 | 进入 `/json.html`，输入合法 JSON 后点“格式化” | `{"a":1}` | 输出区出现格式化结果 | |
| 3 | 回首页 | 无 | “最近处理”新增 1 条 `JSON` 记录；时间为当前；点击该条能回到 `/json.html` | |
| 4 | 点“清空” | 已有至少 1 条记录 | 列表消失，回到空态，清空按钮禁用 | |
| 5 | 切到英文后重复步骤 2–3 | 同上 | 首页区块标题、空态、清空按钮变英文；新增记录的工具名跟随英文 | |

## 不测（本刀）

- 跨浏览器同步
- 失败任务是否入历史
- 搜索、筛选、固定置顶（本刀未做）
