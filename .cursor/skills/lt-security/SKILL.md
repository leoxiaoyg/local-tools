# local-tools · 隐私与安全（SEC）

## 产品红线

- **文件默认不出本机**；任何遥测/上传必须显式、可关、默关
- 「跨境合规」话术不得夸大成法律顾问结论；表述用「有助于隐私控制」级
- PDF 加密/权限、EXIF 清除是信任卖点，验收要可演示

## 威胁关注点

- 上传大小与解压炸弹（zip）
- Office COM / LibreOffice 临时文件残留
- 路径与文件名注入（下载 Content-Disposition）
- 把「赞助解锁」做成绕过基础安全的后门印象（禁止）

## 输出

```markdown
## SEC 意见
### 强化本地优先叙事的项
### 话术风险（过度承诺）
### 实现时必须的安全验收
### 不建议宣传为「合规认证」的项
```
