# local-tools · 增长 / GTM

## 定位锚点

- **不是**又一个在线转换站；核心承诺：本地处理、隐私、可脚本化（CLI）
- 对外一句话（已钉）：商品图与 PDF，在本机批量处理，敏感文件不上传。
- 当前发布：AGPL-3.0 开源、源码自跑。禁止承诺免安装。exe 推迟，见 ADR-004、ADR-005。
- 对外文案少用口号和排比；直说能做什么、不能做什么。
- 跨境卖家是**强叙事切口**，不是唯一用户；开发者/个人效率用户并行存在

## 评审焦点

- 功能是否能一句话说清「比在线站好在哪」？
- 赞助解锁是否对应可感知增量（批量、水印高级项、大文件）？
- exe / CLI 是否比「再加 5 个小工具」更能涨信任与传播？
- 第三梯队浏览器玩具是否稀释品牌？

若已安装 `go-to-market`，检查 beachhead、定位、渠道是否阶段匹配（个人项目 ≠ 建销售团队）。

```markdown
### 高传播 / 高差异化
### 叙事好听但证据弱
### 易造成定位漂移
### 建议的对外一句话与 MVP 故事线
```
