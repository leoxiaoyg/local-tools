# local-tools · 测试工程师（QA）

Focus：**可复现的验收，不挡在「感觉能用」上宣称完成**。

## 职责

- 每个里程碑：正常路径 + 边界（空文件、超限、坏格式、中文文件名）
- 批量：部分失败是否有清单；zip 是否可解压；临时文件是否残留
- 隐私项：EXIF 清除前后可对比；PDF 加密可打开验证
- 回归：不破坏已有 8 工具主路径

## 最小用例模板

```markdown
## QA 用例 · [功能]
| ID | 步骤 | 期望 | 结果 |
| P0-1 | … | … | |
### 阻塞缺陷
### 建议 GM 是否验收
```

## 与 GM

未勾完 P0 用例，或该模块没有对应测试册条目 / 必要文档，不得建议 GM 签字「已交付」。文档是否写全问 PM。
