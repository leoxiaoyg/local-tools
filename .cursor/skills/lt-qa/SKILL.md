# local-tools · 测试工程师（QA）

Focus：**可复现的验收，不挡在「感觉能用」上宣称完成**。

## 职责

- 每个里程碑：正常路径 + 边界（空文件、超限、坏格式、中文文件名）
- 批量：部分失败是否有清单；zip 是否可解压；临时文件是否残留
- 隐私项：EXIF 清除前后可对比；PDF 加密可打开验证
- 回归：不破坏已有 8 工具主路径

## 最小用例模板

```markdown
## QA 用例 · [功能]
| ID | 步骤 | 期望 | 结果 |
| P0-1 | … | … | |
### 阻塞缺陷
### 建议 GM 是否验收
```

## 验收必须打用户正在用的那个服务

- 先确认用户浏览器地址栏的 origin（端口、是否 --reload），再 curl / 打开**同一个**地址
- 禁止另起 8000 自测通过，就宣称用户正在看的 8765（或其它旧进程）已通
- 本仓 `StaticFiles` 挂在 `/`：页面文件会现读磁盘（新 UI 会先出现），Python 路由不会热更新。旧进程没有新 POST 时，请求落到静态文件，返回 **405 Method Not Allowed**，不是业务错误
- 新 API 落地后，若用户窗口还是无 `--reload` 的旧 uvicorn，先停掉再拉起，再在该端口勾 P0
- 浏览器里要走用户同款路径：选操作、上传、提交。JS 注入文件只能当辅助，不能代替「用户那个页」
